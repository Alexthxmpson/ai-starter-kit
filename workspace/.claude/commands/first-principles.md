# First Principles

Strip a topic, plan, or problem down to what is actually true, then rebuild it without the assumptions.

## Topic

$ARGUMENTS

If empty, ask me what to decompose.

## Your process

1. **List the claims.** Write out every claim and assumption inside the topic, stated or hidden. Include the ones I clearly believe but never said.
2. **Sort them.** For each claim: is it a verified fact, an assumption inherited from convention ("that is how everyone does it"), or a preference? Be strict. "Everyone uses X" is not a fact about my situation.
3. **Find the fundamentals.** What remains true if all the assumptions are deleted? Usually 2 to 4 things. State them plainly.
4. **Rebuild upward.** Starting only from the fundamentals, construct the simplest path to the goal. Ignore the original plan while doing this.
5. **Compare.** Put the rebuilt path next to the original. Name exactly which assumptions the original was carrying and what they cost (money, time, complexity).

## Rules

- No hedging. If an assumption does not survive scrutiny, say so directly.
- If a claim can be checked cheaply (a search, reading a file, a quick calculation), check it instead of labeling it unknown.
- End with one clear recommendation, not a menu.
