# ElevenLabs — Capabilities & Use Cases

**API:** ElevenLabs AI Voice Generation
**Access:** ELEVENLABS_API_KEY
**Last updated:** 2026-02-28

---

## What You Can Do

### Free Tier (10,000 characters/month)
- Generate ~10 minutes of spoken audio
- Access all pre-made voices
- Use multilingual model
- 29 languages supported

### Paid Plans ($5–$99/month)
- Voice cloning (from your own voice samples)
- Higher character limits
- Commercial usage rights
- Faster API priority

## Key Notes

- 1 character ≈ 1 character of text (spaces count)
- ~800–1,000 characters per minute of speech
- Free tier = ~10 minutes of audio/month
- Voice cloning requires at least 1 clean audio sample (better with 10–30)
- Streaming endpoint for real-time applications (lower latency)
- `eleven_turbo_v2` = fastest (best for real-time)
- `eleven_multilingual_v2` = highest quality (best for final output)
- Dubbing API handles auto-transcript + translation + re-synthesis
