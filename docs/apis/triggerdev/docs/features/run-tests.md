# Run Tests

You can use the dashboard to test your tasks.

## Testing via Dashboard

Access the "Test" page from the side menu in the dashboard to run tests for any of your tasks across different environments.

## Test Configuration Steps

The testing interface allows you to:

1. **Select a task to test** - Choose which task you want to run
2. **Include a payload or metadata** - Provide input data for your test
3. **Configure additional options** - Set machine size, queue, or delay parameters
4. **Select from previous test runs** - Reuse configurations from earlier tests
5. **Save test templates** - Store your current configuration for future use
6. **Execute the test** - Run your configured test

This streamlined workflow enables you to validate task functionality directly through the Trigger.dev dashboard interface.
