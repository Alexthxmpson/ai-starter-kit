# Contributing

You can participate in Trigger.dev's development across multiple channels. The project welcomes assistance through the [GitHub repository](https://github.com/triggerdotdev/trigger.dev), where you can submit issues or pull requests.

Contribution opportunities include:

* Reporting bugs
* Suggesting new features
* Writing documentation
* Writing code
* Reviewing code
* Translating the app
* Sharing the app with others
* Giving feedback
* And more!

For a complete overview of available documentation, visit: https://trigger.dev/docs/llms.txt
