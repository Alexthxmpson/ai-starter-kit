# Trigger.dev CLI Documentation

## Overview

The Trigger.dev CLI provides a suite of commands and options for local development, self-hosting, and cloud deployment of tasks.

## Global Options

Two primary flags are available across all commands:

- **`--help` / `-h`**: Displays help information for any command
- **`--version` / `-v`**: Shows the current CLI version number

## Available Commands

The CLI includes eight main commands:

| Command | Purpose |
|---------|---------|
| `login` | Authenticate with Trigger.dev to enable authenticated operations |
| `init` | Set up an existing project for Trigger.dev development |
| `dev` | Execute Trigger.dev tasks in a local environment |
| `deploy` | Push your v3 project to Trigger.dev's cloud platform |
| `whoami` | View current user and project information |
| `logout` | End your Trigger.dev session |
| `list-profiles` | View all stored CLI profiles |
| `update` | Synchronize all `@trigger.dev/*` packages with the CLI version |
