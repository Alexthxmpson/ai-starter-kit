# Supabase Overview

This documentation page provides guides and examples for integrating Supabase with Trigger.dev.

## Learning Resources

### Comprehensive Guides

1. **Edge Function Hello World** - Triggering a task from a Supabase edge function when a URL is visited

2. **Database Webhooks** - Trigger a task from a Supabase edge function when an event occurs in your database

3. **Supabase Authentication** - Authenticating Supabase tasks using JWTs for Row Level Security (RLS) or service role keys for admin access

### Practical Examples

1. **Database Operations** - Executing basic CRUD operations on a table in a Supabase database using Trigger.dev

2. **Storage Upload** - Download a video from a URL and upload it to Supabase Storage using S3
