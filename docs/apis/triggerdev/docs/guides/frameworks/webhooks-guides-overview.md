# Using Webhooks with Trigger.dev

## Overview

Webhooks are a way to send and receive events from external services. They facilitate real-time, event-driven functionality by executing code in response to external events — typically through framework routing endpoints.

## Available Guides

1. **Next.js Integration** - Instructions for creating webhook handlers in Next.js applications and triggering tasks from them.

2. **Remix Integration** - Guidance on implementing webhook handlers within Remix apps to initiate tasks.

3. **Stripe Webhooks** - A walkthrough for handling Stripe webhook events, specifically triggering tasks when checkout sessions complete.

4. **Hookdeck Integration** - Demonstrates using Hookdeck as an intermediary to receive webhooks, forward them to Trigger.dev tasks, and provide logging and replay features.

5. **Supabase Database Webhooks** - Instructions for triggering tasks from Supabase edge functions in response to database events.
