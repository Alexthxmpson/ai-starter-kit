# Frameworks, Guides and Examples

## Frameworks

Trigger.dev supports integration with five major JavaScript frameworks:

- **Bun** - Modern JavaScript runtime
- **Next.js** - React-based full-stack framework
- **Node.js** - Server-side JavaScript runtime
- **Remix** - Full-stack web framework
- **SvelteKit** - Svelte-based framework

## Guides

The platform provides comprehensive walkthroughs organized into several categories:

### AI Agent Guides
- Content moderation with parallel checking
- Copy generation and translation workflows
- News article verification systems
- Question routing based on complexity
- Translation evaluation and refinement
- Claude Agent SDK for file reading and code editing

### Framework-Specific Guides
- Cursor rules for task development
- Prisma database setup
- Python image processing with Pillow
- Document-to-markdown conversion
- PDF form extraction using PyMuPDF
- Web crawling with Crawl4AI and Playwright
- Sequin database triggers
- Supabase edge functions and webhooks
- Next.js and Remix webhook integration

### External Services Integration
- Stripe webhook event handling
- Hookdeck webhook forwarding
- Supabase database operations

## Featured Use Cases

Four primary use case categories:

1. **Data Processing & ETL** - Large dataset pipelines without timeout constraints
2. **Media Processing** - Batch video, image, audio, and document processing
3. **AI Media Generation** - Content creation using AI models
4. **Marketing Workflows** - Campaign orchestration and drip campaigns
