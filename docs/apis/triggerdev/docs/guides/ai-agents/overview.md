# AI Agents Overview

## Example Projects Using AI Agents

Trigger.dev provides several real-world AI agent implementations:

- **Claude Changelog Generator**: Automatically creates professional changelogs from git commits
- **Claude GitHub Wiki Agent**: Generates and maintains GitHub wiki documentation with AI-powered analysis
- **Human-in-the-Loop Workflow**: Produces audio summaries of newspaper articles using ReactFlow and Trigger.dev waitpoint tokens
- **Mastra Agents with Memory**: Weather agent that collects live data and generates clothing recommendations
- **OpenAI Agent Python SDK Guardrails**: Implements a guardrails system for AI agents
- **OpenAI Agent TypeScript SDK Playground**: Contains 7 AI agents using the OpenAI Agent SDK
- **Vercel AI SDK Deep Research Agent**: Generates comprehensive PDF reports using research agents
- **Smart Spreadsheet**: Enriches company data using Exa search and Claude with streaming results

## Agent Fundamentals

These guides demonstrate different AI agent workflow patterns inspired by Anthropic's research on building effective agents:

- **Prompt Chaining**: Links multiple prompts together to generate and translate marketing copy
- **Routing**: Directs questions to different AI models based on complexity analysis
- **Parallelization**: Checks for inappropriate content while simultaneously responding to customer inquiries
- **Orchestrator**: Coordinates multiple AI workers to verify news article accuracy
- **Evaluator-Optimizer**: Translates text and improves quality through automated feedback loops
