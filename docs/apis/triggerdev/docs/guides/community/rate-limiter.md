# Rate Limiter

## Overview

A community-contributed rate limiting package for Trigger.dev, created by [@ian](https://github.com/ian) that uses Redis to rate limit Trigger.dev tasks.

## Key Resources

- **Repository**: [View the repo](https://github.com/ian/trigger-rate-limiting)

## Purpose

The package provides rate limiting functionality designed to work with Trigger.dev's task system, utilizing Redis as its underlying infrastructure for managing rate limits.
