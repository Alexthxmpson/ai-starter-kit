# Trigger.dev Documentation

## Overview

Trigger.dev is an open source framework for building reliable background jobs and workflows. It enables developers to write asynchronous code without managing infrastructure, providing built-in queuing, retries, and monitoring capabilities.

## Key Features

The platform offers:
- **Task Management**: Write tasks as plain async code within existing applications
- **Scheduling**: Support for both regular and scheduled (cron) tasks
- **Observability**: Dashboard with full visibility into task execution
- **Real-time Updates**: API and React hooks for frontend integration
- **Flexible Deployment**: Cloud hosting or self-hosted options

## Getting Started

The documentation provides multiple entry points:

**Quick Start**: Get your first task running in approximately three minutes

**Guides & Examples**: Access frameworks and example projects across various use cases

**AI Integration**: Learn to build projects with AI coding assistants

**Video Walkthrough**: Ten-minute end-to-end demonstration

## Core Concepts

| Concept | Purpose |
|---------|---------|
| Tasks | Core units of background work |
| Triggering | Methods to initiate tasks |
| Runs | Individual task executions |
| API Keys | Authentication credentials |

## Available Features

- Scheduled tasks with cron expressions
- Real-time status monitoring
- Error handling and automatic retries
- Concurrency and queue configuration
- Human-in-the-loop approval workflows
- Custom build extensions

## Example Integrations

The platform supports integration with tools including FFmpeg, OpenAI, Puppeteer, Playwright, Browserbase, Sentry, Resend, Supabase, and Deepgram, among others.
