## Getting Started

The original "Getting Started" URL for the Instagram Graph API no longer exists. Meta has reorganized the documentation under the Instagram Platform umbrella.

  https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login

- **Instagram API with Facebook Login (legacy, still supported):**

  https://developers.facebook.com/docs/instagram-platform/create-an-instagram-app

- **Overview:**
  https://developers.facebook.com/docs/instagram-platform/overview

### Key First Steps

1. Create a Meta Developer App at https://developers.facebook.com/
2. Add the Instagram product to your app
3. Configure Business Login for Instagram or Facebook Login for Business
4. Obtain a User access token with the required permissions
5. Use the Graph API endpoints with your token

Refer to `overview.md` for the full platform overview and permission requirements.
