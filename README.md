# AI Command Center

**One folder. Your whole AI setup.** From Alexander Alberts' AI event in Bali.

This repo is not an installer that leaves files somewhere. **The cloned folder becomes your command center**: the workspace where your AI knows who you are, what your business is, where your data lives, and how you like to work. You install once, get interviewed once, and every session after that starts with full context.

## Install

**macOS / Linux (Terminal or Warp):**

```bash
curl -fsSL https://raw.githubusercontent.com/Alexthxmpson/ai-starter-kit/main/install.sh | bash
```

**Windows (PowerShell or Warp on Windows):**

```powershell
irm https://raw.githubusercontent.com/Alexthxmpson/ai-starter-kit/main/install.ps1 | iex
```

## What happens next

The install is three acts, and only the first one is technical:

**1. The installer** checks your machine, installs Claude Code if missing, and clones your command center to `~/ai-command-center`.

**2. The setup wizard** connects your AI to the world. Plugins that need no keys (a browser, live code docs, Notion) connect automatically. For the rest it opens each website for you, tells you exactly where the API key lives, and saves what you paste into your private `.env`. Skip anything; re-run any time with `bash setup/wizard.sh`.

**3. The onboarding interview.** You run:

```bash
cd ~/ai-command-center
claude "/onboard"
```

Claude interviews you: who you are, what your business is, your 90-day goals, what you dream of building, and where your stuff lives (Notion? Airtable? Fathom recordings? A CRM?). It writes all of that into your `context/` folder, generates your personal `CLAUDE.md`, and recommends your first build. From then on, every session starts already knowing you.

## What's inside

```
ai-command-center/            ← this repo, cloned = your workspace
├── CLAUDE.md                 ← generated by /onboard, read every session (private)
├── .env                      ← your API keys (private)
├── .claude/commands/         ← 9 skills
├── .claude/skills/           ← playbooks + helper scripts behind the bigger skills
├── context/
│   ├── about-me/             ← who you are (private)
│   ├── business/             ← overview, goals, resources map (private)
│   ├── ai-consulting/        ← synced from Alexander's portal, if you are a client (private)
│   └── handoffs/             ← session notes: your AI's memory (private)
├── projects/                 ← one folder per build (private)
├── docs/                     ← written guides + saved API docs
└── setup/wizard.sh           ← re-runnable connector wizard
```

Everything marked private is git-ignored: your data never leaves your machine, and `git pull` safely brings in new skills and guides without touching it.

## The skills

| Skill | What it does |
|-------|-------------|
| `/onboard` | The interview + connector walkthrough. Run once, re-run to add more |
| `/brain-dump` | Messy idea in, structured interview, build spec out |
| `/skill-creator` | Interviews you about a process you know, writes it as a new skill |
| `/automation` | Builds one chore-killer: trigger, skill runs, data lands, ping |
| `/dashboard` | Data you already have, live on a real URL |
| `/api-docs` | Saves real API docs before any integration. Never let AI guess an API |
| `/first-principles` | Strips a problem to what is actually true |
| `/handoff` | Ends a session with a note to the next one |
| `/ai-consulting` | For Alexander's consulting clients: pulls your calls, action items and roadmap from his portal, turns them into changes in this repo, ticks items off. See [docs/AI-CONSULTING.md](docs/AI-CONSULTING.md) |

## Updating

```bash
cd ~/ai-command-center && git pull
```

New skills and guides arrive; your `.env`, `CLAUDE.md`, context and projects are untouched.

## Requirements

- macOS, Linux, or Windows
- [Node.js 18+](https://nodejs.org) (the installers handle this on Windows via winget)
- A Claude subscription (Pro or Max) or an API key, to sign into Claude Code
